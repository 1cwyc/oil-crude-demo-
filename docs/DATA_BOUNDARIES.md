# 数据与仓库边界

公共仓库只保存可公开、可复现且体量受控的代码和测试资产。

| 数据类别 | Git 策略 | 存放位置 |
|---|---|---|
| 源码、测试、配置模板 | 跟踪 | 仓库 |
| 不超过 64 KiB 的合成 AIS 样本 | 跟踪 | `sample_data/` |
| 真实 POS/STA | 永不跟踪 | 用户配置的仓库外数据盘 |
| Parquet、DuckDB、CSV、热力图和报告 | 永不跟踪 | 仓库外 `output_root` |
| ChinaPorts 原始响应、Cookie 和浏览器状态 | 永不跟踪 | 仓库外爬虫工作区 |
| `.env`、令牌、密码和 SSH 密钥 | 永不跟踪 | 操作系统凭据位置 |
| 来源许可和字段合同 | 跟踪 | `docs/` 或模块 provenance |

## 允许提交

- 不含真实身份或轨迹的最小合成记录；
- 公开来源的字段名称、解析器测试和许可说明；
- 不可逆的小型聚合示例，且必须由模块 PRD 明确允许；
- 运行命令、行数、质量计数和测试摘要。

## 禁止提交

- 可还原单船真实轨迹或装卸活动的数据；
- 原始网页响应、登录状态、验证码、Cookie 或请求凭据；
- 真实 Parquet、DuckDB、SQLite、压缩数据包和大规模导出；
- 主机用户名、个人目录、临时会话路径或固定盘符的真实业务路径；
- 无权再分发的第三方港口、贸易或船舶数据。

## 路径配置

复制配置模板到仓库外或未跟踪的本地文件中，设置：

- `input_patterns.sta`
- `input_patterns.pos`
- `output_root`
- `duckdb.temp_directory`

代码和版本化配置不得写死某台主机的真实路径。PR 只记录路径是否可读、数据时间范围和 schema 指纹，不记录用户名或凭据。

## 防护层

1. `.gitignore` 防止常见本地文件被误加入。
2. `scripts/check_repository_safety.py` 检查 Git 已跟踪文件。
3. GitHub Actions 在每个 PR 重复执行安全检查。
4. PR 模板要求提交者确认数据边界。

`.gitignore` 不能删除已经跟踪或进入历史的文件。发现疑似泄露时立即停止推送，判断影响范围并更换真实凭据；不要只增加一条忽略规则后继续。
